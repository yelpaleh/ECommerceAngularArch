What Happens When You Run This:
Initially, the child component goes through all lifecycle stages (constructor → ngOnChanges → ngOnInit → etc.).

Clicking "Update Input" triggers ngOnChanges, ngDoCheck, and all Checked hooks.

Clicking "Toggle Child Component" destroys the component and re-creates it — so you'll see ngOnDestroy followed by the full cycle again.
